# LinkedIn Post — AI Process Flow Improvement Agent

I built an **AI Process Flow Improvement Agent in n8n** to support the type of analysis I perform as a **Business Systems Analyst**.

The goal was not simply to generate a process diagram. I wanted the agent to behave more like a Senior Systems Analyst: understand the current process first, identify evidence-supported bottlenecks, separate facts from root-cause hypotheses, preserve required controls, and then design a practical TO-BE process.

The agent can:
- Conduct process discovery and ask focused follow-up questions when information is incomplete
- Document AS-IS process steps with step-level traceability
- Identify bottlenecks, rework, wait states, manual effort, ownership gaps, and integration opportunities
- Distinguish confirmed issues from assumptions and root-cause hypotheses
- Recommend process, system, integration, workflow, and automation improvements
- Preserve security, approval, audit, compliance, and human-oversight controls
- Build a TO-BE process and recommend measurable KPIs
- Generate clickable **AS-IS and TO-BE draw.io process flows directly from the analysis**

For testing, I used an **Employee Software Access Request** process. The agent identified repetitive manual license/software validation and email-based Security approvals as key bottlenecks, then redesigned the future state with stronger intake validation, workflow-based Security approval, automated decision capture, and better routing — without removing the required manager and Security approvals.

This project is a practical example of how I see AI supporting the Business Systems Analyst role: not replacing analysis, but accelerating discovery, documentation, traceability, process visualization, and solution design.
